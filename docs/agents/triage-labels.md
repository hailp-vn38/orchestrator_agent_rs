# Triage labels

| Vai trò | Nhãn trên GitHub | Ý nghĩa |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer cần đánh giá |
| needs-info | needs-info | Chờ người báo cung cấp thêm thông tin |
| ready-for-agent | ready-for-agent | Đủ đặc tả để agent triển khai |
| ready-for-human | ready-for-human | Cần con người triển khai |
| wontfix | wontfix | Không thực hiện |

Khi skill yêu cầu một vai trò triage, dùng nhãn tương ứng trong bảng.
