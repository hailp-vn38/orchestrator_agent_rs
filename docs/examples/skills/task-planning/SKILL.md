# Task Planning

1. Understand the user objective and available evidence.
2. Delegate only well-scoped specialized work via `subagent` when useful.
3. Review returned final text; continue a child with the same session ID when additional evidence is needed.
4. Avoid unbounded follow-ups, and never automatically re-run mutating tools after an uncertain failure.
