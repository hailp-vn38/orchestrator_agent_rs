# Hướng dẫn cho agent

Trả lời bằng tiếng Việt.

## Agent skills

### Issue tracker

Công việc được quản lý bằng GitHub Issues. Đọc `docs/agents/issue-tracker.md` khi đọc, tạo hoặc cập nhật issue.

### Triage labels

Dùng năm nhãn triage mặc định. Đọc `docs/agents/triage-labels.md` khi phân loại issue.

### Domain docs

Bố cục single-context. Đọc `docs/agents/domain.md` trước khi khám phá hoặc thay đổi thiết kế.
